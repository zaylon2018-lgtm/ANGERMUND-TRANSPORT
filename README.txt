DEPLOY:
1. Upload the public folder to your Netlify repo, replacing the old public folder.
2. Publish directory: public
3. Build command: leave empty
4. In Supabase SQL Editor, run SUPABASE_FULL_SCHEMA.sql
5. Open your Netlify site and login with your Supabase user.

This version includes full side menu, fleet, diesel, permits, payroll, workers, maintenance, tyres, workshop jobs, fines/damages, border logs, GPS, invoices/PDF, WhatsApp reports and profiles.
